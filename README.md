# Fantasy Town Generator Viewer
This repository is a personal project I made which asks for the `Map (Geojson)` and `Building and Population details` files downloaded from a [Fantasy Town Generator](https://www.fantasytowngenerator.com/) town and renders the town in a similar aesthetic

The site is live and accessible thanks to Github pages at https://superma30.github.io/FantasyTownGeneratorViewer/
